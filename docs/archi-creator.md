# Archi Creator — визуальный редактор архитектурных моделей

> Статус: спецификация по итогам брейншторма от 2026-09-22. Документ живой:
> решения, которые изменятся по ходу работы, правятся здесь, а не в переписке.

## 1. Обзор

Archi Creator — веб-редактор архитектурных моделей на базе нотации ArchiMate 3.2 с
drag-and-drop-канвой, ИИ-помощником и полной совместимостью с нативным форматом Archi
(`.archimate`). Продукт не клонирует Archi: он берёт его семантику и файловый формат,
но даёт существенно более качественный визуальный язык и встроенного советника, который
объясняет нотацию и находит ошибки в модели.

Ключевая ценность — архитектор работает в современном интерфейсе, а результат остаётся
обычным `.archimate`-файлом, который открывается в Archi без потерь. Это снимает риск
vendor lock-in и позволяет внедрять инструмент постепенно, рядом с существующим Archi.

Референсная модель для разработки и тестов — `docs/Hamkorbank_AS_IS_strict.archimate`
(~400 элементов, ~370 связей, 12 представлений).

## 3. Архитектура

### 3.1 Общая схема

```
┌──────────────────── Браузер ────────────────────┐
│  React + TypeScript                             │
│   ├─ Канва: React Flow, узлы = SVG-компоненты   │
│   ├─ Палитра · Дерево модели · Свойства         │
│   └─ Панель ИИ-помощника (SSE)                  │
└───────────────────────┬─────────────────────────┘
                        │ HTTPS, JWT (Keycloak)
┌───────────────────────┴─────────────────────────┐
│  Spring Boot 4 (Java 25), слоёная архитектура   │
│   web/        REST-контроллеры                  │
│   service/    ModelService, ImportService,      │
│               ExportService, ValidationService, │
│               LockService, VersionService,      │
│               AiService                         │
│   repository/ Spring Data JPA                   │
│   entity/     JPA-сущности                      │
│   archi/      кодек .archimate (JAXB/StAX)      │
└──────┬────────────────┬─────────────────┬───────┘
       │                │                 │
  PostgreSQL 16     Keycloak 26     api.anthropic.com
  (источник правды)  (OIDC)          (Claude Sonnet 5)
```

Фронтенд собирается Maven-сборкой (`frontend-maven-plugin`) и укладывается в тот же jar —
на выходе один артефакт.

### 3.2 Стек

| Слой | Технология |
|------|-----------|
| Язык бэкенда | Java 25 (`maven.compiler.source/target=25`) |
| Фреймворк | Spring Boot 4.x (Web, Data JPA, Security OAuth2 Resource Server, Validation) — согласно внутреннему стандарту Java 25 / Spring Boot 4.x |
| БД | PostgreSQL 16, миграции — Flyway |
| Аутентификация | Keycloak 26, OIDC, JWT |
| XML | StAX для чтения (потоково, большие файлы), DOM/StAX-writer для записи с сохранением порядка |
| Фронтенд | React 19 + TypeScript, Vite |
| Канва | React Flow (`@xyflow/react`), узлы — собственные SVG-компоненты |
| Состояние | Zustand (документ модели) + TanStack Query (серверные данные) |
| Стили | CSS-переменные (токены) + CSS Modules |

## 10. Развёртывание

### 10.1 Состав

`docker-compose.yml` на внутреннем сервере банка:

| Сервис | Образ | Порт | Назначение |
|--------|-------|------|-----------|

### 10.2 Сборка

```
mvn clean package
  └─ frontend-maven-plugin: npm ci && npm run build → target/classes/static
  └─ spring-boot:repackage  → target/archi-creator-1.0-SNAPSHOT.jar
docker compose build && docker compose up -d
```

### 10.3 Профили и конфигурация

| Профиль | Особенности |
|---------|-------------|
| `dev` | PostgreSQL в Docker, Vite dev-сервер с прокси на `:8080`, авторизация отключена (заглушка `ARCHITECT`), ИИ через реальный ключ или мок |
| `prod` | Keycloak обязателен, CORS закрыт, Flyway `validate`, логи в JSON |

Секреты (`ANTHROPIC_API_KEY`, пароль БД, client secret Keycloak) — через переменные
окружения и `.env`, вне репозитория.

### 10.4 CI

GitHub Actions / внутренний CI: сборка → юнит-тесты → golden-file тесты →
интеграционные тесты (Testcontainers) → сборка фронтенда → Playwright → публикация образа.
