# Этап 4. Домен advisor

**Дата:** 2026-10-16. **Репозиторий:** ветка `cr_phase_1`, после `ddd5831` (исправления этапа 3 уже в коде).
**Стандарт:** коммит `97bce16`, §2.6–§2.7, §3.3.1–§3.3.6, §3.3.10, §4.3.1, §4.13.3, чеклист §5.3.
**Объём:** `archi-advisor/archi-advisor-domain` — 58 файлов, ~2,0 тыс. строк; прочитан целиком, без субагентов.
Использование доменных типов в `archi-advisor-application` (`ContextPlanner`, `ResultReader`) и схема
`V4__advisor.sql` сверены точечно. 04-02, 04-03 и 04-07 подтверждены прогоном скомпилированных классов
(одноразовые пробы вне репозитория).

Правила, которые держит сборка с этапов 1–3 (var, импорты, Javadoc, сложность, `Optional` в полях
и параметрах, `BaseId`, `AggregateRoot`, имена событий, фабрики событий вне домена), здесь не перепроверялись.
