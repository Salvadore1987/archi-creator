## Проверено — нарушений нет

| Пункт плана | Результат |
|---|---|
| Порты | интерфейсы в `application.port`, реализации — в адаптерах и `bootstrap`; `Optional` — результат поиска |
| Транзакция | только через `UnitOfWork`, `@Transactional` нет; события публикуются через порт и уходят после коммита; внешние вызовы — 05-01 |
| Роль на границе use case'а | каждый публичный сценарий с актором идёт через `kernel.run` → `AccessPolicy.require`; таблица `Operation` совпадает с `authorization` спецификации; системные методы (`committed`, `recordGitSha`, `purgeSnapshots`, `store`) без актора — их зовут фоновые обработчики и interchange со своей проверкой роли |
| Порядок отказов записи | роль → модель и список доступа (скрытая — `404`) → состояние → блокировка, в одном месте — `ModelingKernel.writableModel`; исключения — 05-06 |
| Умолчания со смыслом | папка по слою, папка представлений, комментарий отката и создания, пространство по умолчанию — в сервисах, а не в контроллерах |
| Маппинг | DTO собирает `DtoMapper` адаптера REST; в application HTTP-объектов, JPA и Jackson нет (enforcer) |
