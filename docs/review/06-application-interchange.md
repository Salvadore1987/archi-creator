# Этап 6. Application interchange: импорт, экспорт, раскладка

**Дата:** 2026-10-19. **Репозиторий:** ветка `cr_phase_6`, после `b7d06a6` (исправления этапа 5 уже в коде,
application modeling переведён на входные порты, handler'ы и DTO).
**Стандарт:** коммит `97bce16`, §3.3.7 (порты, DTO, сервисы, маппинг), §3.5, §4.8, Приложение C, чеклист §5.3.
**Объём:** `archi-interchange/archi-interchange-application` — корень пакета, `importing/`, `exporting/`,
`mapping/`, `port/`: 35 файлов, ~3,2 тыс. строк; прочитаны целиком, без субагентов (порог протокола
превышен на ~0,7 тыс. строк — разбивать `mapping/` отдельно не было смысла, его находки всё равно
сверяются по коду). Точечно сверены: `InterchangeController`, обработчики ошибок, проводка
`InterchangeConfiguration`, читатель `StaxArchiDocumentReader`, `VersionContents` modeling,
`spec/nfr/interchange.yaml`, `export-view-image.md`, `docs/backend.md` §5.2.
