# Этап 8. Application interchange: Git

**Дата:** 2026-10-21. **Репозиторий:** ветка `cr_phase_8`, после `ab92495` (исправления этапа 7).
**Стандарт:** коммит `97bce16`, §3.3.7 (application-слой), §4.4.4 (секреты в журнале), §4.8 (транзакции),
§4.11 (outbox), чеклист §5.3.
**Объём:** `archi-interchange/archi-interchange-application/.../application/git/` — 13 файлов, ~3,2 тыс. строк.
Три субагента, каждый прочитал свою часть целиком: публикация и outbox (`GitPublishingService`,
`GitBindingService`, `GitBindingSettings`, `GitRemotes`, `GitPositions`); импорт по ссылке и слияние
(`GitImportService`, `GitMergeService`, `GitAttempts`); YAML (`GitYamlWriter`, `GitYamlReader`, `GitYamlFormat`,
`YamlEmitter`, `PositionPlan`). Находки YAML 08-08, 08-10, 08-11, 08-20 воспроизведены на SnakeYAML 2.5
с той же конфигурацией. Корректностные находки перепроверены по коду до записи: 08-01…08-07, 08-09, 08-11,
08-12, 08-15. Точечно сверены: `SecretRef`, `GitBinding`, `EnvironmentSecretResolver`, `JGitRepository`,
`JpaGitOutbox`, `GitConfiguration`, `GitController`, `ApplicationLayerTest`.
