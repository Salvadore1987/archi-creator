# Исправления по этапу 15 ревью — архитектурные проверки в сборке

**Основание:** находки [`docs/review/15-arkhitekturnye-proverki.md`](../review/15-arkhitekturnye-proverki.md);
порядок работы — как в планах этапов 1–14 (владелец 2026-10-22: «если есть изменения — сразу исправь»).

Каждая задача — проверка в сборке, прогон на старом коде (обязан упасть), перенос всех мест,
тесты затронутых модулей зелёные, один коммит. Код этапа почти везде уже соответствует правилу:
там, где нарушений нет, «прогон на старом коде» — порча правила или кода на время прогона.

## Порядок

Сначала решение о раскладке портов (1) — правило задачи 2 опирается на него. Затем правила ArchUnit (2–4, 7–9),
формат и PMD (5, 6). Порядок объявлений (10) — последним: перестановка трогает 31 файл, и остальные задачи
не должны с ней пересекаться.
