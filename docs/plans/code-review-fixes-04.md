## Расхождения плана с фактом

- **2.** `fit` возвращает `Optional`: не помещается даже без элементов — пусто, а сценарий отвечает
  тем же отказом, что при малом покрытии (`CONTEXT_TOO_LARGE`). Представления по-прежнему
  не отбрасываются — без них ревью не видит устройства модели. Новый тест на старом коде
  не компилируется (другой тип результата); что старый `fit` отдаёт контекст сверх предела,
  показала проба ревью: `fit(1000)` → 31 445 токенов.
- **3.** Вид проверяется одним правилом с `ElementRef` (`ElementRef.validArchiId`). Отказ — без
  значения в тексте: строка любой длины не должна вернуться в ответе. Ограничение записано
  в контракте OpenAPI (`maxLength`, `pattern`).
- **4.** Правило стало общим для трёх доменов и запрещает ещё и ловить `NullPointerException`.
  В modeling оно нашло пять мест — встроенный каталог типов, ресурс матрицы связей, SHA-256 отпечатка
  команды: все ошибки программиста, внесены в список исключений правила, код не менялся.
