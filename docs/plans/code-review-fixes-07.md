## Расхождения плана с фактом

- **Задача 1, ошибка по ходу.** Первая версия `Routing.endpoint` принимала
  `Function<String, Optional<Rect>>` — тот же `Optional` в параметре, только отложенный.
  `CodingRulesTest` её пропустил: проверял сырой тип параметра (`Function`), а не аргументы
  дженерика. Владелец заметил 2026-10-21. Лечение — задача 0: правило смотрит и аргументы
  дженериков параметров и полей; на старом коде оно нашло ещё `DocumentAssembler`
  (`Map<String, Optional<String>>` в четырёх методах — теперь `null` значит «типизирован,
  значения нет», `containsKey` по-прежнему отличает его от нетипизированного). `Routing.endpoint`
  принимает карты фигур и связей. Возврат `Optional<Rect>` остаётся: это результат поиска конца.
