# Исправления по этапу 9 ревью — application advisor

**Основание:** находки [`docs/review/09-application-advisor.md`](../review/09-application-advisor.md);
порядок работы — как в планах этапов 1–8 (владелец 2026-10-21: «если есть изменения — сразу исправь»).

Каждая задача — проверка в сборке или тест, прогон на старом коде (обязан упасть),
перенос всех мест, `./mvnw -P '!frontend' install` зелёный, один коммит.

## Порядок

Сначала запрет сборки (1), затем деньги: двойной поток и недосписание (2, 3), транзакции и метрики (4),
детали отказа при повторе (5), мелочи (6). Перевод на входные порты и handler'ы (7) — по уже
исправленному коду.

## Задачи

| № | Задача | Находки | Проверка | Статус |
|---|---|---|---|---|
| 1 | Исключения основного кода — непроверяемые; `LlmUnavailableException` — `RuntimeException` | 09-01 | `CodingRulesTest`: класс основного кода, наследующий `Exception` не через `RuntimeException`, роняет сборку | ✅ |
| 2 | Сессия занимает ключ до отказов и до внешнего API | 09-02 | `AdvisorIdempotencyTest`: ключ уже занят — `409`, `open` не вызван; `AdvisorIT`: два параллельных обращения с одним ключом — один поток | ⬜ |
| 3 | Обрыв потока списывает выход по оценке | 09-03 | `AnthropicLlmClientTest` (подменный сервер): поток рвётся после текста — расход выхода не меньше оценки | ⬜ |
| 4 | Допуск — одним чтением; внутри записи без вложенной транзакции; метрика бюджета — после коммита | 09-04, 09-06 | `AdvisorServiceTest`: фейк `UnitOfWork` отказывает вложенной транзакции; настройки и бюджет читаются одной | ⬜ |
| 5 | Повтор отклонённой сессии — с деталями отказа | 09-05 | `AdvisorIdempotencyTest`: повтор `BUDGET_EXHAUSTED` — дата сброса, `RATE_LIMITED` — ожидание | ⬜ |
| 6 | Окно частоты снимается, когда опустело; ключ JSON экранируется | 09-07, 09-08 | `RateLimiterTest`, `ContextJsonTest` | ⬜ |
| 7 | Advisor — входные порты, handler'ы, DTO | 09-09 | `ApplicationLayerTest` с контекстом advisor; `AdvisorHandlersTest`: роль до работы у всех сценариев | ⬜ |

Находка 09-10 (счётчик повторов SDK Anthropic) переносится в этап 13 — адаптер Anthropic читается там целиком.
