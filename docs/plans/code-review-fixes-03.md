## Расхождения плана с фактом

- **1.** Проверка — в бизнес-методах агрегатов modeling (имена, документация, свойства, точка
  зрения, подпись и текст узла, шрифт стиля), а не в конструкторах значений: через конструкторы
  модель грузится из базы, и запись, сделанная раньше через API, не должна делать модель
  нечитаемой. Последний рубеж — значения документа interchange и строгий кодировщик писателя:
  старая запись с таким символом теперь роняет выгрузку отказом, а не пишет битый или
  искажённый файл.
