# UC-ADV-001 — Ревью модели

**Актор:** `ARCHITECT`, `VIEWER` · **Триггер:** запрос ревью модели
или представления · **Результат:** список находок со ссылками на объекты модели

Помощник не изменяет модель. Результат ревью — текст и ссылки; правки вносит
только архитектор (FR-22). Это не ограничение реализации, а граница ответственности:
модель — предмет решений человека.

## Предусловия

- `workspace.ai_enabled = true` (FR-27).
- Месячный бюджет токенов не исчерпан (FR-51, `INV-ADV-005`).
- Частота запросов пользователя в пределах лимита (FR-52).

## Основной сценарий

**Given** модель на 400 элементов и включённый помощник

**When** актор запрашивает ревью

**Then**
1. Отказ по бюджету, выключенному помощнику или частоте принимается **до**
   расхода токенов (`INV-ADV-002`, `INV-ADV-005`).
2. Собирается `ModelContext`: элементы, связи, имена, типы — в пределах верхней
   границы размера контекста. При усечении контекст помечается,
   и пометка видна в ответе (`INV-ADV-007`, FR-52).
3. Создаётся `AdvisorSession`; повтор с тем же ключом идемпотентности
   не тратит токены заново (`INV-ADV-003`).
4. Запрос уходит в Anthropic API с сервера. Ключ и содержимое промпта
   не покидают сервер (`INV-ADV-009`, NFR-06).
5. Ответ приходит потоком (SSE), первые токены ≤ 3 с (NFR-04).
6. Находки разбираются в `Finding`: нарушения матрицы связей, элементы-сироты,
   дубли по смыслу, пропущенные связи между слоями, несогласованные имена.
   Каждая находка обязана ссылаться на объект модели (`INV-ADV-008`, FR-23)
   и содержать описание исправления.
7. Расход списывается с бюджета; бюджет не уходит в минус и не уменьшается
   задним числом (`INV-ADV-006`).
8. Пишется `AuditEntry`: обращение, функция, пользователь, токены
   (`INV-ADV-001`, FR-27, FR-53).
9. Публикуется `AdvisorSessionCompleted`.

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| Помощник выключен | `403`, `ADVISOR_DISABLED` | Панель сообщает, что функция отключена администратором |
| Бюджет исчерпан | `429`, `BUDGET_EXHAUSTED` | Панель сообщает о бюджете и дате сброса; редактор работает без изменений (FR-51) |
| Превышена частота | `429`, `RATE_LIMITED` + `Retry-After` | Повторить позже (FR-52) |
| Контекст больше предела | `413`, `CONTEXT_TOO_LARGE` | Предложение сузить область: представление вместо модели |
| Anthropic API недоступен | `503` | Панель показывает ошибку, остальной редактор работает |
| Находка без ссылки на объект | отбрасывается | Находка, на которую нельзя перейти, бесполезна (`INV-ADV-008`) |

## Порты

**Входящий:** `ReviewModel(modelId, scope, idempotencyKey)` → поток `Finding`

**Исходящие:**
- `ModelContextReader` — чтение элементов и связей (запрос в `modeling`)
- `LlmPort` — обращение к Anthropic API, потоковый ответ
- `TokenBudgetPort` — резерв и списание расхода
- `AuditWriter` — запись обращения
