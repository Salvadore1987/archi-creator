# UC-MDL-002 — Создать элемент и разместить его на представлении

**Актор:** `ARCHITECT` · **Триггер:** перетаскивание с палитры или из дерева
(UI-002) · **Результат:** элемент в модели и, при размещении, узел представления

Сценарий разделён надвое сознательно: элемент существует в модели один раз
и размещается на произвольном числе представлений (FR-11). Создание элемента
и его размещение — разные команды.

## Предусловия

- Блокировка модели принадлежит актору (`UC-MDL-005`, `INV-MDL-006`).
- Тип элемента поддержан фазой 1: Business, Application, Technology (FR-07).
- Целевая папка существует и принадлежит этой модели.

## Основной сценарий

**Given** открытая модель с действующей блокировкой и выбранный тип
`ApplicationComponent`

**When** актор создаёт элемент с именем и целевой папкой

**Then**
1. Проверяется блокировка: запись без действующей блокировки, принадлежащей
   автору команды, отклоняется (`INV-MDL-006`).
2. Генерируется `UUIDv7` как внутренний ключ и `archi_id` формата
   `id-<32 hex>` ([`ADR-0002`](../../../adr/0002-dual-identity.md)), уникальный в пределах модели (`INV-MDL-001`).
3. `sort_order` в пределах папки назначается разреженно, шагом 1000: вставка
   не перенумеровывает соседей (`INV-MDL-005`).
4. При размещении на представлении создаётся `ViewNode` с `bounds`
   относительно родителя; у ребёнка `Group` — относительно группы.
5. Модель помечается как изменённая; версия не создаётся — её создаёт
   сохранение (`UC-MDL-004`).

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| Блокировки нет или она чужая | `409` | Показывается владелец блокировки, предлагается read-only |
| Тип фазы 2 или 3 | `422` | Создание недоступно; импортированные объекты таких типов остаются opaque (FR-03, UI-020) |
| Папка из другой модели | `422` | Отказ: дерево папок принадлежит модели |
| Размещение уже размещённого элемента | `200` | Возвращается существующий узел, дубль не создаётся (UI-002) |

## Порты

**Входящие:** `CreateElement(modelId, archiType, name, folderId)`,
`PlaceElementOnView(viewId, elementId, bounds)`

**Исходящие:** `ElementRepository`, `ViewRepository`, `LockGuard`,
`ArchiIdGenerator`
