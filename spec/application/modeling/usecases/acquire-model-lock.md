# UC-MDL-005 — Захватить и освободить блокировку модели

**Актор:** `ARCHITECT` (захват, освобождение), `ADMIN` (принудительное снятие) ·
**Результат:** право записи у одного редактора, остальные видят модель read-only

## Предусловия

- Модель в состоянии `ACTIVE`.

## Основной сценарий

**Given** модель без действующей блокировки

**When** актор открывает её на редактирование

**Then**
1. Создаётся `ModelLock` на актора с временем захвата и сроком действия.
2. Любая команда записи проверяет, что блокировка действует и принадлежит
   автору команды (`INV-MDL-006`).
3. Остальные пользователи видят модель read-only с именем владельца блокировки.
4. Освобождение владельцем даёт причину `RELEASED_BY_OWNER`, снятие
   администратором — `FORCED_BY_ADMIN`, истечение срока — `EXPIRED`.
5. Публикуется `ModelLockReleased`.

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| Модель заблокирована другим | `409` | Показывается владелец, предлагается открыть read-only (§8) |
| Запись с истёкшей блокировкой | `409` | Отклоняется; клиент перезахватывает и повторяет |
| Принудительное снятие ролью `ARCHITECT` | `403` | Только `ADMIN` (FR-05) |
| Снятие блокировки при несохранённых изменениях | `409` + подтверждение | Изменения принадлежат сессии редактора и будут потеряны — требуется явное согласие |

## Порты

**Входящие:** `AcquireLock(modelId)`, `ReleaseLock(modelId)`,
`ForceReleaseLock(modelId)`

**Исходящие:** `ModelLockRepository`, `Clock`

## События

`ModelLockReleased`
