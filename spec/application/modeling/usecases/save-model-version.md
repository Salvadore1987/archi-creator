# UC-MDL-004 — Сохранить модель, создав версию

**Актор:** `ARCHITECT` · **Триггер:** кнопка «Сохранить» (появляется только при
наличии изменений, UI-017) · **Результат:** новая неизменяемая версия модели

## Предусловия

- Есть несохранённые изменения относительно точки сохранения.
- Блокировка принадлежит актору (`INV-MDL-006`).

## Основной сценарий

**Given** модель с изменениями и комментарий к сохранению

**When** актор сохраняет модель

**Then**
1. Все изменения применяются одной транзакцией: промежуточных состояний
   в базе не возникает (NFR-07).
2. Создаётся `ModelVersion` с автором, временем, комментарием и монотонно
   возрастающим номером. Версия неизменяема (`INV-MDL-010`).
3. Снимок содержимого сохраняется при версии; правило ретеншена
   (последние 30 дней, помеченные версии, последняя за месяц) применяется
   позже и только при настроенном Git (FR-46, FR-47).
4. Точка сохранения в истории сдвигается, счётчик несохранённых изменений
   обнуляется, отметки в дереве снимаются (UI-017).
5. Публикуется `ModelVersionCommitted`; при настроенной привязке за ним следует
   публикация в Git (`UC-IXC-003`).

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| Конкурентное сохранение без блокировки | `409` | Клиент перезагружает состояние и повторяет (NFR-07) |
| Повтор с тем же ключом идемпотентности | `200` | Возвращается результат первой попытки, вторая версия не создаётся (`INV-MDL-003`) |
| Тот же ключ, другое тело | `409` | Расхождение запроса и сохранённого результата |
| Изменений нет | `200` | Версия не создаётся: журнал версий — не журнал нажатий |
| Пометка версии (`label`) | `200` | Помеченная версия считается релизом, её снимок не удаляется (FR-48) |

## Порты

**Входящие:** `SaveModel(modelId, comment, idempotencyKey)`,
`LabelVersion(versionNo, label)`, `RollbackToVersion(versionNo)`

**Исходящие:** `ModelVersionRepository`, `SnapshotWriter`, `LockGuard`,
`GitPublisher` (необязателен)

## События

`ModelVersionCommitted`
