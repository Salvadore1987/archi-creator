# UC-IXC-003 — Коммит версии модели в Git

**Актор:** `ARCHITECT` (косвенно — сохранение модели) ·
**Триггер:** зафиксирована новая версия модели ·
**Результат:** коммит в ветке привязки рабочего пространства

Git здесь — журнал и предмет ревью, не способ хранения: источник правды остаётся
в PostgreSQL. Из этого следует направление обмена и запрет на переписывание
истории.

## Предусловия

- У рабочего пространства настроена и доступна привязка `GitBinding`
  в состоянии, допускающем запись.
- Версия модели зафиксирована (`UC-MDL-004`) — коммитится версия, а не текущее
  состояние редактора (`INV-IXC-008`).

## Основной сценарий

**Given** рабочее пространство с рабочей привязкой к репозиторию и новая версия
модели с комментарием автора

**When** система публикует версию в Git

**Then**
1. Модель раскладывается в YAML: `model.yaml`, `folders.yaml`, файл на элемент,
   на связь, на представление; имя файла — `<слаг>.<8 hex от id>.yaml`
   (`INV-IXC-011`).
2. Принадлежность папке пишется полем `folder`, порядок — разреженным `position`
   с шагом 1000; неподдержанное уходит в `raw_xml` блочным скаляром.
3. Писатель детерминирован: фиксированный порядок ключей, сортировка свойств,
   LF, без якорей и переносов. Повторная публикация без изменений модели diff
   не даёт (FR-40).
4. Коммит добавляется в ветку: автор — архитектор, сообщение — комментарий
   к сохранению. Только fast-forward, без force push и rebase (`INV-IXC-009`).
5. `git_sha` записывается в версию модели — по нему потом восстанавливается
   очищенный снимок (FR-46).
6. Публикуется `GitSnapshotCommitted`.

## Как запускается

Версия попадает в очередь **той же транзакцией**, что фиксируется: событие
`ModelVersionCommitted` пишется в `outbox_event` (`ADR-0003`). Фоновый
обработчик проходит очередь по порядку версий внутри модели; `POST
/models/{id}/git/push` проходит очередь модели немедленно. Повтор после сбоя
между push и записью `git_sha` находит уже сделанный коммит по трейлерам
и не создаёт второго.

Раскладка — обратимое кодирование снимка версии: из дерева коммита собирается
тот же документ, и писатель `.archimate` даёт те же байты, что снимок. На этом
стоит восстановление очищенного снимка (FR-46).

Каталог модели — `models/<слаг>.<8 hex от ModelId>/`. Найденный в HEAD каталог
сохраняется и при переименовании модели. Позиции наследуются из HEAD: вставка
одного объекта не перенумеровывает соседей.

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| HEAD ветки сдвинулся коммитом, тронувшим каталог модели, или наш последний коммит перестал быть предком HEAD | расхождение | Экспорт помечается как расхождение (`DIVERGED`) и **не** перезаписывает чужой коммит (FR-37); следующие версии модели ждут за ним; разрешается импортом (7b) или слиянием по сущностям (`INV-IXC-010`, этап 7c) |
| HEAD сдвинулся коммитом вне каталога модели (README, другая модель) | публикация | Коммит ложится сверху, fast-forward; чужое не трогается |
| Модель не менялась с прошлого коммита (дерево совпало) | без коммита | Версия получает `git_sha` текущей головы: содержимое уже там |
| Репозиторий недоступен | отложено | Версия остаётся в базе, публикация повторяется; очистка снимков при этом выключена (FR-47) |
| Привязки нет | пропуск | Сохранение модели проходит полностью, Git не участвует, снимки не удаляются никогда |
| Модель физически уничтожена (`PURGED`) | коммиты не трогаются | Репозиторий остаётся журналом (`INV-IXC-009`) |

## Порты

**Входящие:** `PushModelToGit(modelId)` → `ModelGitStatus` (очередь модели сейчас);
`ConfigureGitBinding(workspaceId, settings)`; обработчик outbox без актора.

**Исходящие:**
- `GitYamlWriter` / `GitYamlReader` — детерминированная раскладка модели по файлам
  и обратная сборка документа
- `GitRepositoryPort` — fetch/чтение дерева/commit/push, только fast-forward
- `SecretResolver` — учётные данные по `SecretRef`, в базе не хранятся
- `GitOutbox` — очередь версий из `outbox_event`
- `PublishedVersions` — снимок версии и запись `git_sha` в неё (команда в `modeling`)

## События

`GitSnapshotCommitted` — [`../../../domain/interchange/events.yaml`](../../../domain/interchange/events.yaml).
Фиксация самой версии — `ModelVersionCommitted` из `modeling`.

## Решение о доставке

`ADR-0003`, принят 2026-10-13: в outbox идёт `ModelVersionCommitted`, `git_sha`
пишется одной транзакцией с закрытием записи outbox, `GitSnapshotCommitted` —
`direct`-уведомление после неё.
