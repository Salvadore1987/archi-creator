# UC-IXC-004 — Экспорт представлений в SVG и PNG

**Актор:** `VIEWER` и выше · **Триггер:** запрос картинки одного представления
или всех представлений модели · **Результат:** файл `.svg`/`.png` либо zip
с файлом на представление, и отчёт о потерях

Картинку печатает сервер — браузер пользователя в этом не участвует, поэтому
выгрузка работает и по API, и пакетом. Канва и сервер рисуют по одной геометрии
(`shapes.json`), одним токенам и одному спрайту иконок (`UI-019`); расхождение
ловит сверка канвы и экспорта.

## Предусловия

- Модель существует и не удалена; актор видит её (список доступа, FR-29).
- Указана версия либо берётся последняя зафиксированная (`INV-IXC-008`).

## Основной сценарий — одно представление (`ExportViewImage`)

**Given** сохранённая модель и представление в ней

**When** актор запрашивает `fmt=svg` или `fmt=png` с параметрами `scale`,
`outline`, `background`

**Then**
1. `ExportJob` фиксирует `sourceVersionNo`; картинка строится из снимка этой
   версии, правки после сохранения в неё не попадают (`INV-IXC-008`).
2. Представление ищется в снимке по `archiId`; его нет в версии — отказ.
3. Узлы рисуются контурами из `shapes.json`, цвет — собственный стиль объекта,
   иначе токен слоя (FR-21); иконки — из общего спрайта; связи — по маршруту
   и с наконечниками своего типа; подписи переносятся по ширине на сервере.
4. Экспортируется представление целиком по границам содержимого, с полями.
5. `outline=true` переводит подписи в кривые; без него текст остаётся текстом,
   а шрифт вшит в файл подмножеством глифов.
6. PNG растеризуется из того же SVG с подписями в кривых в плотности `scale`.
7. Отчёт о потерях есть всегда (`INV-IXC-006`): объект неподдержанного типа
   нарисован заглушкой, шрифт объекта заменён, подпись усечена, изображение
   узла не нарисовано. Число записей — в заголовке ответа.
8. Результат отдаётся как `Artifact`, публикуется `ExportCompleted`.

## Пакетный сценарий — все представления (`ExportAllViewImages`)

**When** актор запрашивает все представления модели в одном формате

**Then** все картинки строятся из **одного** снимка (`INV-IXC-008`): архив
не смешивает версии. Файл на представление — `<слаг>.<8 hex>.<ext>`, слаг
транслитерирован в латиницу, 8 hex — из `archiId`; отчёт о потерях всех
представлений — `loss-report.json` в том же архиве.

## Альтернативы и отказы

| Ситуация | Ответ | Поведение |
|---|---|---|
| Представления нет в запрошенной версии | `404` | `IXC_VIEW_NOT_IN_VERSION`: выгружается только сохранённое |
| `fmt`, `scale` или `background` вне допустимых значений | `422` | `IXC_UNKNOWN_FORMAT` либо `IXC_INVALID_EXPORT_OPTION` |
| PNG стороной больше 16 000 px (4 000 × 4 000 при `scale=4`) или площадью больше 64 Мпикс | `422` | `IXC_IMAGE_TOO_LARGE` с наибольшей допустимой плотностью; SVG предела не имеет |
| Растеризатор занят дольше 60 с — PNG растеризуется по одному на процесс | `503` | `IXC_RASTERIZER_BUSY`: повторить позже |
| Модель удалена | `409` | `MODEL_DELETED` |
| Снимок версии очищен, Git не настроен | `410` | Как у `UC-IXC-002` (FR-47) |

## Порты

**Входящие:** `ExportViewImage(viewId, fmt, scale, outline, background, versionNo?)` → `Artifact`;
`ExportAllViewImages(modelId, fmt, scale, outline, background, versionNo?)` → `Artifact` (zip)

**Исходящие:**
- `VersionSnapshotReader` — снимок версии
- `Typesetter` — метрики и контуры глифов шрифта интерфейса
- `Rasterizer` — SVG в PNG; заменяем (Batik сейчас, `resvg` при нужде)
