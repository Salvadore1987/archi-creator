# ADR-0025 — Логирование: Logback и встроенный формат ECS

## Статус

Принято 2026-10-14 по итогам этапа 0 ревью кода (отклонение D-09), решение владельца
проекта. Отступает от внутреннего стандарта `java-spring-code-guidelines-v2.md` в §4.4.1,
§4.4.3 и приложении D (№ 19).

## Контекст

Стандарт требует SLF4J + Log4j2 с `JsonTemplateLayout` по общему шаблону `JsonLayout.json`
и исключает Logback из сборки; встроенный структурированный формат Spring Boot
(`logging.structured.format.console: ecs`) он рассмотрел и отверг как основной — ради
одного шаблона на все сервисы.

В проекте — Logback (стартер по умолчанию), в профиле `prod` — JSON в формате ECS:
`traceId`, `spanId` и MDC (корреляция запроса, пользователь, модель) — поля, а не текст
строки. `docs/backend.md` §8.4 требует структурированных логов с этими полями — требование
выполнено.

Archi Creator — одно приложение, один jar; общего с другими сервисами сбора логов,
который ждёт поля шаблона `JsonLayout.json`, у него нет.

## Рассматриваемые варианты

**1. Перейти на Log4j2 и шаблон стандарта.** Исключить `spring-boot-starter-logging`,
подключить Log4j2, завести шаблон и конфигурацию. Выгода появится, только когда логи
пойдут в общий сбор, рассчитанный на этот шаблон.

**2. Оставить Logback и ECS.** Формат встроен в Spring Boot 4, конфигурации — одна
строка в `application-prod.yaml`; ECS — открытая схема Elastic, её разбирают
распространённые системы сбора логов.

## Решение

Вариант 2. Логирование — SLF4J API, реализация Logback; в `prod` — JSON в формате ECS
на консоль, файловых appender'ов нет.

Остальные требования стандарта к логированию действуют без изменений: уровни (§4.4.2),
маскирование чувствительных данных (§4.4.4), корреляция через MDC с очисткой
в `finally` (§4.4.7), плейсхолдеры вместо конкатенации, «log and throw» запрещён (§4.4.9).

## Последствия

- Находки ревью по выбору фреймворка и формата не заводятся.
- Решение пересматривается, когда логи приложения начнут собираться общей платформой
  банка с требованием к формату: переход тогда — замена стартера и конфигурации,
  код вызовов SLF4J не меняется.
