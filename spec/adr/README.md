# Архитектурные решения

Индекс — [`decisions.yaml`](decisions.yaml), единственный регистр решений
проекта: и архитектурных, и продуктовых, и форматных.

Обоснование лежит в одном из двух мест, и третьей копии не создаётся:

- **`NNNN-<slug>.md` рядом** — для решений, принятых при раскатке спеки
  (`ADR-0001`…`ADR-0003`): у них своего разбора в `docs/` нет.
- **Раздел `docs/`** — для двенадцати решений, закрытых 2026-09-22
  (`ADR-0004`…`ADR-0015`): разбор написан там раньше, чем появился этот индекс.
  Поле `rationale_ref` ведёт прямо в него.

Журнал в [`docs/archi-creator.md` §13](../../docs/archi-creator.md#13-открытые-вопросы)
остаётся как есть — он хронология обсуждения, а `decisions.yaml` — регистр
состояний. Вопрос из §13 не удаляется, а зачёркивается с датой.
