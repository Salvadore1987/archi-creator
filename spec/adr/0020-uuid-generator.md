# ADR-0020 — UUID создаются и разбираются только через java-uuid-generator

## Статус

Принято 2026-10-13. Уточняет [`ADR-0001`](0001-maven-multi-module.md): у доменных
модулей появляется одна зависимость.

## Контекст

Идентификаторы агрегатов — UUID версии 7: время в старших битах, ключ вставляется
в индекс по порядку. До решения UUID создавались тремя способами:

- три собственные копии генератора `UuidV7` — по одной в домене каждого контекста,
  потому что доменные модули друг от друга не зависят;
- `UUID.randomUUID()` (версия 4) там, где версия не продумывалась, — ключ
  идемпотентности импорта, тесты;
- `UUID.fromString` и `new UUID(long, long)` для разбора и сборки значений.

Три копии побитовой сборки по RFC 9562 — три места для одной ошибки в битах версии
или варианта, а случайный v4 рядом с v7 размывает «все ключи монотонны».

## Решение

UUID создаются и разбираются только библиотекой
[`com.fasterxml.uuid:java-uuid-generator`](https://github.com/cowtowncoder/java-uuid-generator)
(JUG). Тип значения остаётся `java.util.UUID` — библиотека выдаёт его же.

- **Создание** — `Generators.timeBasedEpochGenerator(…)` (версия 7, монотонна
  в пределах миллисекунды). Классы `UuidV7` контекстов остаются тонкой обёрткой:
  они передают библиотеке часы приложения (`java.time.Clock`), чтобы тесты
  фиксировали время.
- **Разбор строки** — `UUIDUtil.uuid(String)`: строже `UUID.fromString`, принимает
  только 36-символьную запись.
- **Запрещены** в коде и тестах: `UUID.randomUUID()`, `UUID.nameUUIDFromBytes(…)`,
  `UUID.fromString(…)`, конструктор `new UUID(long, long)`.
- Версия библиотеки — в `dependencyManagement` родителя; `slf4j-api`, которую
  библиотека объявляет, исключён: генератор версии 7 и разбор строки его не трогают,
  и доменные модули остаются без логгера.

Правило держит сборка — `UuidRulesTest` в `archi-bootstrap`: ArchUnit по байткоду
основного кода и проверка исходников всех модулей, тестов включительно.

## Последствия

- У `archi-<bc>-domain` одна зависимость — JUG. Фреймворков в домене по-прежнему
  нет: правило `maven-enforcer-plugin` из `ADR-0001` не меняется.
- Чужой код (Spring разбирает `UUID` в параметрах пути) правилом не охвачен —
  оно о коде проекта.
- Фронтенд правило не затрагивает: библиотека — Java, у браузера свой генератор
  версии 7 (`model/ids.ts`).
